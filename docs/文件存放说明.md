# 小林 AI 助手文件存放说明

整个项目统一存放在 `D:\Workspace\AI_Project`。

## 主要目录

- `data/`：记忆、会话、任务、提醒、微信登录状态、日志和收到的附件，属于私人数据。
- `workspace/`：助手生成的工作文件、截图、视频抽帧和拉片报告。
- `backups/`：本地自动备份。
- `exports/`：手动导出的个人数据包。
- `persona/`：助手人格设定。
- `tests/`：自动化测试与旧版手动冒烟测试。
- `venv/`：主助手的轻量 Python 运行环境。
- `local_assets/runtime/`：大型本地 AI 独立运行环境。
- `local_assets/models/`：本地模型权重。
- `local_assets/tools/`：FFmpeg 等配套工具。
- `local_assets/cache/`：安装和下载缓存。项目稳定后可单独清理这一目录。

## C 盘内容

C 盘只保留桌面快捷方式和 Windows 登录启动快捷方式，大小只有几 KB。程序、模型、缓存、私人数据和工作输出均存放在上述 D 盘项目目录。

## 注意

不要手动移动 `data/`、`venv/` 或 `local_assets/` 中的单个文件。如果将来需要整体迁移，应移动整个 `AI_Project` 文件夹并重新生成桌面与启动快捷方式。
