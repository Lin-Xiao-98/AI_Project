# AI 助手运行环境与恢复说明

这份说明用于回答两个问题：GitHub 保存了什么，以及换电脑或本地文件缺失后如何恢复。

## GitHub 会保存的内容

GitHub 保存程序源码、启动脚本、自动化测试、依赖清单、配置示例和说明文档。克隆仓库后可以恢复程序结构，但不能仅凭 GitHub 直接恢复本机模型、私人资料或登录状态。

## GitHub 不会保存的内容

| 内容 | 本机位置 | 不上传原因 | 恢复方式 |
|---|---|---|---|
| OpenAI API Key、微信令牌 | Windows DPAPI 与 `data/` | 属于密钥，且 DPAPI 只对当前 Windows 用户有效 | 在控制台重新保存 API Key；微信重新扫码 |
| `.env` | 项目根目录 | 可能包含本机配置 | 从 `.env.example` 复制并重新设置 |
| 记忆、会话、任务、提醒 | `data/` | 私人数据 | 从自己的加密/离线备份恢复 |
| 微信收到的附件和日志 | `data/inbox/`、`data/logs/` | 私人内容 | 通常无需恢复 |
| 主 Python 环境 | `venv/` | 文件多且与电脑相关 | 根据 `requirements.txt` 重建 |
| Qwen 语音运行环境 | `local_assets/runtime/` | 约 3.58 GB | 重建或从自己的 D 盘备份复制 |
| Qwen 语音模型 | `local_assets/models/` | 约 4.21 GB，超过 GitHub 适用范围 | 从官方模型源重新下载 |
| FFmpeg | `local_assets/tools/` | 约 0.60 GB 的第三方二进制文件 | 从 FFmpeg 官方页面重新安装 |
| 下载缓存 | `local_assets/cache/` | 约 2.23 GB，可随时重建 | 不必恢复 |
| 语音、截图和拉片报告 | `data/audio/`、`workspace/` | 私人或生成内容 | 按需要从个人备份恢复 |

`backups/` 和 `exports/` 也不会上传 GitHub。GitHub 负责保护代码版本，不等于私人数据备份。

## 当前已验证的环境

- Windows 11 x64
- Python 3.13.15
- NVIDIA RTX 5060 Laptop GPU，CUDA 可用
- 主项目依赖：见根目录 `requirements.txt`
- PyTorch 2.11.0+cu130
- torchaudio 2.11.0+cu130
- qwen-tts 0.1.1
- modelscope 1.40.2
- soundfile 0.14.0
- Qwen3-TTS-12Hz-1.7B-VoiceDesign
- FFmpeg 9.0.2 essentials build

本地 Qwen 语音需要支持 CUDA 的 NVIDIA 显卡。没有兼容显卡时，可以把 `.env` 中 `TTS_PROVIDER` 改为 `openai`，使用云端备用语音，但会产生 API 用量。

## 最快恢复方式

如果只是重装程序而 D 盘数据仍在，保留完整的 `D:\Workspace\AI_Project` 即可。不要单独移动 `venv/`、`data/` 或 `local_assets/` 内部文件。

如果换了电脑，推荐顺序如下：

1. 从 GitHub 克隆项目到 `D:\Workspace\AI_Project`。
2. 安装 Git、Python 3.13 和最新 NVIDIA 驱动。
3. 重建主 Python 环境。
4. 恢复 FFmpeg、本地 Qwen 运行环境和模型。
5. 从 `.env.example` 创建 `.env`。
6. 打开控制台重新保存 API Key。
7. 重新扫码绑定个人微信。
8. 双击 `验收AI助手.bat`，按失败项目修复。

## 重建主 Python 环境

在 PowerShell 中运行：

```powershell
cd D:\Workspace\AI_Project
py -3.13 -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

不要把 API Key 直接写进可提交的文件。打开“小林AI助手控制台”，使用“安全更新 API 密钥”，程序会保存到 Windows DPAPI 密钥库。

## 恢复 FFmpeg

从 [FFmpeg 官方下载页面](https://www.ffmpeg.org/download.html) 进入 Windows builds，下载 essentials build，解压后保证文件位于：

```text
D:\Workspace\AI_Project\local_assets\tools\FFmpeg\bin\ffmpeg.exe
D:\Workspace\AI_Project\local_assets\tools\FFmpeg\bin\ffprobe.exe
```

当前已验证压缩包的 SHA-256 为：

```text
60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba
```

版本更新后校验值会变化，应以下载站当时公布的校验值为准。

## 恢复本地 Qwen 语音

目标运行环境：

```text
D:\Workspace\AI_Project\local_assets\runtime\Qwen3-TTS\venv
```

当前已验证版本的重建命令：

```powershell
cd D:\Workspace\AI_Project
py -3.13 -m venv .\local_assets\runtime\Qwen3-TTS\venv
.\local_assets\runtime\Qwen3-TTS\venv\Scripts\python.exe -m pip install --upgrade pip
.\local_assets\runtime\Qwen3-TTS\venv\Scripts\python.exe -m pip install --index-url https://download.pytorch.org/whl/cu130 torch==2.11.0+cu130 torchaudio==2.11.0+cu130
.\local_assets\runtime\Qwen3-TTS\venv\Scripts\python.exe -m pip install qwen-tts==0.1.1 modelscope==1.40.2 soundfile==0.14.0
```

如果未来这些固定版本无法下载，应使用 [PyTorch 官方安装选择器](https://pytorch.org/get-started/locally/) 选择与显卡驱动兼容的 CUDA 版本，并参考 [Qwen3-TTS 官方仓库](https://github.com/QwenLM/Qwen3-TTS) 更新安装方式。

模型必须最终位于：

```text
D:\Workspace\AI_Project\local_assets\models\Qwen3-TTS\Qwen3-TTS-12Hz-1.7B-VoiceDesign
```

其中至少应存在：

```text
config.json
model.safetensors
tokenizer_config.json
vocab.json
```

`model.safetensors` 当前约 3.83 GB。明显小于 3 GB 通常表示下载不完整。

可以使用 ModelScope 下载：

```powershell
.\local_assets\runtime\Qwen3-TTS\venv\Scripts\modelscope.exe download --model Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign --local_dir .\local_assets\models\Qwen3-TTS\Qwen3-TTS-12Hz-1.7B-VoiceDesign
```

## 一键判断失败位置

双击根目录的：

```text
验收AI助手.bat
```

新版检查会分别显示：

- Python 版本
- OpenAI API Key
- 长期记忆文件
- SQLite 数据库
- 核心程序文件
- 本地 FFmpeg
- 本地 Qwen 运行环境、模型与 CUDA
- 个人微信本机登录状态
- 企业微信状态

## 常见错误对照

| 提示 | 原因 | 处理办法 |
|---|---|---|
| `OpenAI API Key：未配置` | 密钥不会上传 GitHub | 在控制台重新安全保存 API Key |
| `个人微信登录：需重新扫码绑定` | 微信令牌和账号状态不会上传 | 启动个人微信助手并扫码 |
| `缺少 model.safetensors` | 本地模型不存在或下载不完整 | 按上面的模型恢复步骤下载 |
| `未检测到可用 NVIDIA CUDA` | 显卡驱动、CUDA 版 PyTorch或硬件不满足 | 更新 NVIDIA 驱动并重装匹配的 PyTorch；或切换云端 TTS |
| `本地语音依赖损坏` | 移动了运行环境内部文件或安装中断 | 删除并重建 `local_assets/runtime/Qwen3-TTS/venv` |
| `缺少 ffmpeg.exe` | FFmpeg 没有恢复到固定位置 | 按上面的目录重新解压 |
| `个人微信登录凭证已过期` | 腾讯令牌到期 | 重新扫码绑定 |
| `达到 API 每日硬上限` | 本机费用保护触发 | 等次日重置或在确认预算后调整 `.env` 上限 |
| `无法连接 github.com:443` | 当前网络无法访问 GitHub | 不影响本地助手运行；网络恢复后重新 `git push` |

如果“一键验收”全部通过但微信仍无回复，应先查看控制台后台状态和 `data/logs/weixin_bot.log` 的末尾错误。不要把日志中可能包含的私人内容公开上传。
